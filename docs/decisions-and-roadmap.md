# 决策与实施路线

## 1. 已确认

| 决策 | 内容 |
| --- | --- |
| 使用人群 | 公开给其他学习者 |
| 访问场景 | 海外用户 |
| 学习水平 | 能听懂大意，重点改善发音与表达 |
| 主要设备 | 手机优先，兼容电脑 |
| 当前目标 | 先做可体验版本 |
| 首批人物 | 仅莱维特 |
| 本轮工作 | 已授权本地开发；暂不考虑远程仓库，不推送或发布 |

## 2. 建议默认值，尚未由用户单独确认

中文界面、工作名称 Briefly、暖白与深绿视觉、3～5 节课程、游客使用、本机保存、无账号和付费。可在下一阶段开始前调整，不把这些写成用户已明确要求。

网站架构保留未来增加其他人物的可能；第一版页面和素材仅展示莱维特。

## 3. 待验证问题

| 问题 | 处理方式 | 是否阻止页面设计 |
| --- | --- | --- |
| 素材嵌入与使用条件 | 逐条验证官方来源 | 否；阻止未验证媒体公开上线 |
| 句子循环精度 | 在候选播放器和手机上实际测试 | 否；影响播放器实现 |
| 独立音频 | 确认可取得的文件及处理条件 | 否；可延后 |

| 网站名称及域名 | 正式品牌使用前确认 | 否 |

## 4. 后续实施顺序

### A. 素材验证

选择一场候选记者会，完成一个问答片段的媒体验证、字幕校对、时间轴和教学内容。交付一张可追溯的素材记录及一节真实样课。先解决完整课程可行性，再扩充数量。

### B. 体验原型

实现首页、课程学习页、收藏与本机记录。打通一节课的四步流程，之后扩充到 3～5 节。使用占位内容时明确标记，不把占位当真实课程完成。

### C. 可体验版本验收

- 手机 360～430px 宽与电脑 1280px 宽没有横向溢出，字幕清楚，按钮容易操作。
- iOS Safari、Android Chrome 与桌面浏览器验证播放、切句、循环和录音；记录实际版本与结果。
- 验证拒绝麦克风、媒体加载失败、存储失败与刷新恢复。
- 第一节课能从首页进入并完成听懂、模仿、活用、开口与收藏复习。
- 无需登录；本机数据提示明确，录音不在未经选择时上传。
- 键盘可操作，字幕不单靠颜色区分，放大后内容仍可使用。

### D. 分享与发布

用户确认分享方式后选择托管并生成可访问链接。域名购买、收费服务或公开发布不属于本轮设计工作。素材未准备好时，只能交付注明限制的界面原型。

## 5. 如何衡量首版是否有用

先观察学习者是否能独立完成第一节课、是否理解录音对照、是否能在新问题中使用目标表达。初期可通过试用反馈验证；无需为此立刻接入跟踪服务或收集录音。

## 6. 维护规则

需求变化时先更新本文件中的确认状态，再同步页面设计与内容规范。技术栈待开发阶段结合媒体方案决定，避免在素材可行性尚未验证前固化架构。

## 7. 本地实现调整

使用原生 JavaScript 模块与静态页面，无需第三方运行依赖。三节微片段体验课先验证流程，暂未达到最初每节 1～3 分钟的完整课程长度。已实现功能与验证范围见 [实现记录](implementation.md)。原始设计中的视觉建议作为参考，采用暖白与深绿。域名、云托管、账号与跨设备同步仍未纳入本轮。

## 8. 已确认的新一轮优化（2026-10-24）

用户确认执行字幕选择复制、独立发音技巧、活用例句朗读、课程与片段两级结构，并补充第 1 期素材。当前第 1 期含 8 个片段（原有 3 个，加 5 个）。完整说明见 [本轮变更](changes-2026-10-24.md)。仍限本地，不推送、不发布。

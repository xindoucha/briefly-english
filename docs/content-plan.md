## 2. 播放方案的决策顺序

1. 优先验证官方原片能否通过平台支持的方式嵌入，是否允许第三方站点播放。
2. 测试时间跳转、句子循环、调速、手机播放和字幕同步；记录播放器精度限制。
3. 需要独立音频或更精准控制时，查找使用条件明确、可合法取得的媒体文件，逐条确认后再决定是否托管。
4. 保留原始链接、制作主体、核查日期与处理记录。新闻机构的转播版本不能因拍摄对象是政府官员就自动视作同等使用条件。

当前没有确定任何素材的授权结论。原型可以先用界面示意，但必须标注“示例”，真实课程上线前完成以上验证。

## 3. 选课原则

优先：音质清楚、问答完整、可迁移表达多、背景知识负担低、问题听得清楚的片段。

避免：依赖大量时事背景、只有攻击性措辞、记者提问无法辨识、脱离前文难以理解的短句。保留足够上下文，并提供原片入口。

拟定课程方向（不是已找到的实际片段）：

| 方向 | 沟通目标 | 迁移练习 |
| --- | --- | --- |
| 先说结论，再解释原因 | 组织清楚的回答 | 解释一个工作决定 |
| 澄清问题中的误解 | 温和纠正前提 | 澄清项目进度误会 |
| 补充背景 | 让听者理解语境 | 说明计划变化 |
| 回应追问 | 保持回答重点 | 回答同事的进一步提问 |
| 表达立场 | 兼顾明确与语气 | 对建议提出不同意见 |

能否制作这些课程取决于真实素材审看；不为配合标题杜撰台词。

## 4. 单课内容结构

- 课程 ID、标题、能力分类、难度及判断依据。
- 原片标题、日期、制作主体、来源链接、媒体使用依据与验证状态。
- 课程起止时间（秒）、问答背景、学习目标。
- 字幕句列表：ID、起止时间、说话人、英文、中文、校对状态。
- 精选模仿句：对应字幕 ID、重音／停顿／连读提示。
- 目标表达：原文位置、含义、语气、适用场景、原创迁移例句。
- 开口练习：新问题、可展开提示、原创示范答案和自评项。

字幕时间使用原片绝对时间；界面再换算课程内时间，避免两套时间轴混用。跟读只读完整句，必要时将长句拆成有意义的短语。

## 5. 编辑流程

收集来源 → 验证媒体与使用条件 → 审看片段 → 转写 → 人工核对英文 → 对齐时间与说话人 → 翻译 → 标注发音与表达 → 编写迁移练习 → 手机试学 → 发布课程。

校对重点：专有名词、数字、否定词、记者声音、被打断句子与听不清部分。无法可靠辨认时标记听不清，不猜写。翻译保留原意和语气，表达改写与原文分别呈现。

## 6. 课程可体验标准

- 来源、日期、完整问答与片段范围可追溯。
- 视频能实际播放，字幕逐句匹配，无明显累计偏移。
- 目标表达能迁移到非政治场景，语气讲解明确。
- 模仿句与开口问题均可完成，录音不可用时有替代路径。
- 中文翻译和自编例句明确区分；没有虚构引用、评分或参与人数。

# 本地体验版实现记录

## 当前范围

以零第三方构建依赖的 HTML、CSS、JavaScript 模块实现。使用 Node 内置 HTTP 服务器本地预览，构建时复制必要资源到 dist/。没有后台服务、账号或云存储。最初仅本地开发；用户现已授权推送至 GitHub 并发布到自有域名，发布进度见 [部署记录](deployment.md)。

保留产品设计文档作为最初设计基线；下述调整记录当前实现与基线的区别。

相较最初 1～3 分钟课程设想，本版使用微片段练习；课程对应完整一期视频。包含陈述节选、记者问候以及两组真实追问与回应，不把所有片段都标为完整问答。原有三个片段的存储 ID 和句子顺序保持不变。

视频远程读取 Wikimedia Commons 文件，文件页标注为联邦政府公有领域作品，并列出 The White House 来源。未下载或再托管大体积原片。公开字幕提供时间轴；英文未完成人工复听，不标注“已人工校对”。翻译、提示、理解题和迁移例句为本站编写。

原片地址和字幕记录保存在 src/data.js。用户点击播放后优先连接官方 YouTube 隐私增强嵌入，失败时尝试 Wikimedia Commons 直连。保留来源链接与重试提示；字幕定位与循环复用同一套媒体控制，实际精度受平台影响。提供的调速值遵循播放器实际能力。

## 功能

- 首页课程入口；课程页能力筛选、8 个片段、本期进度、完整视频入口。
- 四步学习、英文与中文开关、时间定位、语速、单句循环。
- 可选择的字幕正文、独立播放按钮、单句／整段复制；只更新字幕高亮，不打断文本选择。
- 独立发音技巧模块、原声回听；解释常见语流规律，明确待原声核验。
- 活用例句语音朗读、正常／慢速选择与播放互斥。
- 手机练习区排在视频下方，完整字幕随后；桌面双栏。
- 录音开始、停止、即时回放、原声→录音对照、本机保存与导出。
- 本机收藏、学习步骤与显式完成标记；刷新后恢复。
- 我的页面：学习足迹、保存录音、数据管理。
- 来源、隐私、浏览器条件与无隶属关系说明。

收藏与进度使用 localStorage，主动保存的录音使用 IndexedDB。未保存的录音离开当前句子会丢失，界面已提示。录音不上传，清除数据需用户确认。

- JavaScript 语法检查通过。
- 静态构建通过。

- 本地首页 HTTP 响应为 200。
- 内置浏览器检查：首页、四步切换、收藏显示、刷新恢复、完成页与复习入口。
- 在 423px 手机宽度和 1280px 桌面宽度检查首页与页面布局；已检查的页面未发生横向溢出。
- 视频能够读出约 2814 秒的原片总时长，但测试环境在片段起点持续缓冲，未验证连续画面及真实音频。
- 因直连源缓冲较慢，改为优先官方 YouTube。已在内置浏览器中显示真实原片画面，并验证第一句播放后停止与字幕匹配。未完成所有课程和全部速度的精度检查。
- 本轮浏览器检查：旧收藏与完成状态仍可读、一期 8 段目录、从字幕进入对应句的发音技巧、复制成功提示、例句朗读按钮状态。
- 已用浏览器实际拖选字幕，确认选中内容为 `Good afternoon, everybody.`，字幕正文不在按钮内；自动化剪贴板读取未返回内容，因此没有宣称完成跨应用粘贴验证。

## 尚待验收

- iOS Safari 与 Android Chrome 真机视频、连续播放和单句循环精度。
- 官方 YouTube 全部课程的完整播放、切句、循环与调速精度。
- 人工复听并调整字幕时间轴、翻译与发音提示。
- 用户真实麦克风的录制、回放、保存和导出；未自动授权或使用用户麦克风。
- 隐私模式、存储配额不足以及不同录音格式兼容性。
- 手机长按选择、跨应用粘贴和不同系统声线的实际听感；内置浏览器的朗读状态检查不能替代真机音频验收。

这些待验收项影响媒体与教学质量，当前版本属于本地功能体验版，不应宣称正式课程或全平台验收完成。

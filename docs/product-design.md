# 产品与页面设计 v0.1

更新日期：2026-10-23。本文为设计方案，不代表已有可运行产品。

2026-10-24 补充：本文保留最初设计基线；当前已实现本地版本，并改为“课程 → 片段”结构，加入发音技巧和例句朗读。最新范围见 [本轮变更](changes-2026-10-24.md)。

## 1. 定位

工作名称：**Briefly｜英语开口练习**。名称尚未确认，正式使用前检查重名与域名。

产品主张：用一段真实问答，练出自己的表达。

面向海外、能听懂英语大意、希望改善发音与表达的学习者。第一批内容仅使用 Karoline Leavitt（莱维特）记者会素材。界面暂定中文，英文为学习主内容；海外指访问与部署场景，不自动等同于英文界面。

核心任务：在约 10～15 分钟内，完成一个短片段的理解、关键句模仿与一次独立回答。时间仅为课程设计目标。

记者会中的政治观点属于原始素材；讲解聚焦语言，不把发言内容当作已核实事实。避免使用可能让人误认为白宫官方产品的名称、徽章或视觉标识。

## 2. 第一版边界

包含：3～5 节经验证的示例课、视频播放、同步英文字幕、可展开中文翻译、切句与循环、调速、录音对照、表达讲解、收藏、本机进度保存、响应式布局。

每节约 1～3 分钟，精选 3～5 个模仿句、2～3 个表达、1 个迁移问题。具体数量以内容完整性为准。

暂不包含：账号、跨设备同步、付费、社区、自动发音评分、自动生成课程、离线媒体下载。独立音频模式依赖素材获取条件；未验证前不承诺提供。

游客可完成全部示例课。跨设备兼容指两端均可使用，第一版不等于进度同步。

## 3. 学习流程

### 听懂

首次播放显示课程目标，英文字幕可一键开启，中文默认收起。学习者可先听完整片段，再查看问答原文。用一个轻量理解问题辅助判断是否抓住大意；允许跳过，不设考试门槛。

### 模仿

进入精选句列表，当前句突出显示。原声播放后，由用户主动点击录音；结束后可以交替播放原声与自己的录音。用“重音、停顿、连读”提示引导观察，不生成未经验证的口音分数。

录音状态：未录制 → 请求麦克风 → 录制中 → 已录制 → 回放。提供重录、删除、保存到本机。拒绝麦克风时仍可播放、看提示并自行练习。录音回放与原声互斥，避免声音叠加。

### 活用

每个表达展示：原句、含义、语气、常见结构、一个日常或职场例句。明确标记“日常可用”“正式”“可能显得强硬”等适用场景。迁移例句必须注明为本站编写。

### 开口

围绕同一沟通能力提出新问题。默认先显示问题，按需展开关键词或示例答案。用户录下约 30～60 秒回答；提供自评项：是否先回答问题、是否使用目标表达、重点是否清楚。完成或跳过均可继续，课程完成需用户明确点击。

完成页展示本次练习、已收藏表达和“再练一次／下一课”。不把播放结束或页面停留当成掌握。

## 4. 页面与导航

手机底部三个入口：学习、收藏、我的。学习页内部使用四步标签，避免与底部全局导航同时争夺空间；进入课程后隐藏全局底栏，保留返回入口。

| 页面 | 内容 | 首要动作 |
| --- | --- | --- |
| 学习首页 | 继续学习、推荐课程、能力筛选、课程卡片 | 继续或开始一课 |
| 课程简介 | 学习目标、来源日期、片段时长、重点表达预览 | 开始学习 |
| 课程学习 | 视频、字幕、四步练习与播放控制 | 执行当前练习 |
| 完成页 | 练习记录、收藏、下一课 | 继续学习 |
| 收藏 | 表达／句子、课程出处、复习入口 | 返回句子练习 |
| 我的 | 本机进度、保存的录音、设置与清除数据 | 管理学习记录 |

能力筛选以“清楚解释、直接回答、澄清误解、回应追问”为主。少量课程时只显示现有分类，不做空分类和复杂搜索。

课程卡片展示标题、沟通目标、时长、难度、字幕校对状态、学习进度；不展示虚构学习人数和评分。

录制完成后，用“原声／我的录音／对照回放”替换主要按钮区，并显示重录与删除。录制中有明显计时、停止按钮与文字状态，不能仅靠颜色传达。

## 6. 电脑布局

建议 ≥1024px 使用双栏：左侧约 56% 为视频、课程信息与来源；右侧为步骤、字幕和练习。768～1023px 根据可用空间使用单栏或紧凑双栏；手机单栏。布局断点以实际内容测试调整。

最大内容宽度约 1200px。字幕区滚动不强制跳动；用户手动查看上文后暂停自动跟随，显示“回到当前句”。

快捷键：空格播放／暂停，左右方向键切句，L 切换循环。输入框、录音操作控件获得焦点时不得触发全局快捷键；不使用单键直接开启麦克风。

## 7. 播放与字幕规则

- 课程以完整原片的起止时间定位，课程进度展示片段内时间，同时可查看原片时间和完整来源。
- 点击字幕跳转到句首；普通播放自然前进，句子循环需显式开启。提供关闭循环入口。
- 建议速度选项：0.75×、0.85×、1×、1.15×；以播放器实际能力为准，不显示不可用选项。
- 英文字幕与翻译分别开关；记者和发言人均标注身份。长句按短语分组，尽量不截断问答逻辑。
- 用户按下播放前不自动发声；录音前暂停原声，回放前停止其他音频。
- 外部嵌入不可用时显示来源链接与重试；如果没有许可明确的本地替代视频，不伪装成可播放。
- 若嵌入播放器无法满足精细切句或后台音频需求，记录限制并调整实现或素材方案。

## 8. 视觉方向

气质：安静、清晰、有编辑感，让字幕与练习占据主要注意力。

| 项目 | 建议值 |
| --- | --- |
| 页面背景 | #F7F7F2 暖白 |
| 卡片 | #FFFFFF |
| 主文字 | #202823 |
| 次要文字 | #59665F |
| 主要动作 | #215B49 深绿 |
| 当前句背景 | #E8F1EA |
| 边线 | #D9E2DA |
| 字体 | 系统无衬线，英文可用系统字体栈 |
| 正文／字幕 | 16px／20～24px，允许放大 |
| 触控目标 | 至少 44×44px，主要按钮建议 48px 高 |

重音用字重，停顿用分组或分隔符；颜色只作辅助。正式实现时检查文字对比度、焦点可见性、键盘操作、200% 缩放和减少动画设置。

## 9. 隐私与异常状态

第一版无账号，收藏和进度保存在当前浏览器。明确说明清除浏览器数据可能丢失记录。录音使用本机存储的建议方案，需实现时验证浏览器容量与格式兼容；不静默上传。

必须设计：首次进入、无收藏、课程加载中、视频失败、字幕缺失、麦克风被拒绝、录音格式不支持、本机存储失败与清除数据确认。保存失败时允许继续练习，并明确提示当前结果未保存。

完整媒体课程未就绪时展示“待校对／暂不可学习”，不以虚构字幕或无关视频填充可用课程。

# 英语视频学习网站

面向海外英语学习者，以莱维特白宫记者会为第一批素材，训练发音、表达与真实问答听力。手机优先，兼容电脑。

当前阶段：可运行体验版本，代码已推送至 [xindoucha/briefly-english](https://github.com/xindoucha/briefly-english)。已加入 GitHub Pages 自动发布配置，域名与上线状态见 [发布记录](docs/deployment.md)。原始视频远程加载，不包含在项目中。

## 本地运行

需要 Node.js 22 或更新版本，无需安装第三方依赖。

```sh
npm run dev
```

打开 <http://127.0.0.1:4173>。停止服务使用 Ctrl+C。

```sh
npm test       # 核心数据与存储逻辑测试
npm run build # 生成 dist/，可交给静态托管服务
```

## 已实现

- 手机与电脑布局；按“完整视频 → 一期课程 → 多个片段”组织，第 1 期包含 8 个片段。
- 听懂、模仿、活用、开口四步练习，听力理解题与迁移情境。
- 视频、音频专注模式、语速、字幕定位、单句循环与中文开关。
- 字幕支持直接选中、单句复制和整段复制；播放按钮与字幕文字分开。
- 每句独立“发音技巧”：连读、弱读、不完全爆破、重音分组等常见规律与练习方法。
- 活用例句提供正常／慢速朗读，优先美式英语系统声线，明确区分合成语音和原声。
- 原声与录音交替回放，录音保存到 IndexedDB、导出与删除。
- 收藏、学习步骤与完成状态保存到当前浏览器。
- 官方视频、媒体许可和字幕来源说明；失败与权限提示。

点击播放优先连接官方 YouTube 隐私增强嵌入，失败时尝试 Wikimedia Commons 远程 WebM。内置浏览器已验证 YouTube 显示原片画面及句子播放；第三方视频的网络、格式、嵌入限制仍会影响实际体验，尚未完成手机真机与麦克风验收。第 1 期素材均来自 2025-01-28 记者会，8 个片段约 2～27 秒，包含陈述节选与真实追问。英文和时间轴仍需人工复听，发音技巧标注为常见规律，不冒充已核验的个人发音转写。

旧的收藏、录音与学习进度继续使用原来的片段 ID 和存储键；旧 `#/lesson/:id` 链接仍可打开。

## 项目结构

- `src/app.js`：页面、学习流程与媒体控制。
- `src/data.js`：课程内容、来源与时间轴。
- `src/storage.js`：收藏和进度存储。
- `src/recordings.js`：本机录音存储。
- `src/youtube.js`：官方 YouTube 备用播放器适配。
- `src/pronunciation.js`：按片段与句子组织的发音技巧。
- `src/speech.js`：例句朗读、英语声线选择与播放取消。
- `src/transcript.js`：按字幕语言开关组织复制文本。
- `src/style.css`：响应式视觉与交互样式。
- `scripts/`：零依赖本地服务器与静态构建。
- `tests/`：Node 内置测试。

界面和文案不依赖外部字体或图片。视频需要联网；例句朗读使用设备的浏览器语音服务，部分系统声线可能联网处理例句文本。录音需要 HTTPS 或 localhost，不会上传。
